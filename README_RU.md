# StageCue — музыкальный пульт для сцены

## Сборка двойным нажатием
1. Windows 10/11 x64.
2. Установи **.NET 10 SDK**: `winget install --id Microsoft.DotNet.SDK.10 -e`
3. Для фирменного установщика также нужен **Inno Setup 6**: `winget install --id JRSoftware.InnoSetup -e`
4. Дважды нажми `build.cmd`.

Результаты:
- `artifacts/portable/StageCue.exe` — автономный EXE, .NET Runtime на целевом ПК не нужен.
- `artifacts/installer/StageCue-Setup-x64.exe` — установщик с выбором каталога, ярлыками, опциональным автозапуском и деинсталляцией Windows.
- `artifacts/installer/SHA256.txt` — контрольная сумма установщика.

Если Inno Setup не установлен, скрипт попробует установить его через winget. Если автоматическая установка недоступна, автономный EXE всё равно будет собран; установи Inno Setup вручную и запусти `build.cmd` повторно.

## Хранение
Музыкальные файлы не копируются. StageCue сохраняет ссылки на исходные файлы и список треков в `%LOCALAPPDATA%\StageCue`. Удаление приложения не удаляет пользовательскую библиотеку.

## Горячие клавиши
- `1–9`, `0`: выбрать треки 1–10 без автоматического запуска
- `Alt + 1–9`, `0`: выбрать треки 11–20 без автоматического запуска
- `Ctrl + 1–9`, `0`: выбрать треки 21–30 без автоматического запуска
- `Ctrl + Alt + 1–9`, `0`: выбрать треки 31–40 без автоматического запуска
- `Пробел`: играть / пауза
- `Enter`: текущий трек сначала

Глобальные клавиши работают, пока приложение запущено. Windows может не зарегистрировать сочетание, если оно уже занято другим приложением.


## Выбор момента и контрольная точка

В нижней панели плеера есть шкала времени. Нажми на неё или перетащи ползунок в нужный момент:
- `Пробел` — воспроизведение/пауза; после выбора момента продолжит с него.
- `Ctrl + Пробел` — сохранит выбранный момент как постоянную контрольную точку этого трека и запустит воспроизведение с неё. Точка сохраняется в библиотеке.
- `Enter` — запуск текущего трека с самого начала.

Контрольная точка хранится отдельно для каждой мелодии.


## Совместимость сборки

Проект нацелен на `net8.0-windows`, поэтому его можно собирать установленным .NET SDK 8, 10 или 11. Скрипт больше не требует строго SDK 10 и принимает любую версию SDK начиная с 8.
Публикация выполняется с `--self-contained true` и `PublishSingleFile=true`: на целевом Windows-компьютере устанавливать .NET Runtime отдельно не требуется.
Примечание: .NET 8 уже завершил период поддержки в ноябре 2026 года. Для долгосрочного выпуска лучше перейти на .NET 10; текущая настройка сделана ради совместимости с имеющимися SDK.


## Исправление сборки WPF

В проекте явно указаны `ApplicationDefinition` для `App.xaml` и `Page` для `MainWindow.xaml`. Автоматическое подключение этих XAML-элементов отключено, чтобы избежать ошибки WPF markup compiler `MC1002/BG1003` на некоторых версиях SDK. Совместимость сборки рассчитана на SDK 8, 10 и 11.


## Обновление интерфейса 0.2

Интерфейс переработан в сторону полноценного настольного приложения:
- обычное отдельное окно Windows с системным управлением окном;
- собственная тёмная палитра, навигация и стили элементов;
- страницы «Главная», «Моя лента», «Фонотека», «Бинды клавиш», «Настройки»;
- цифровая сетка быстрого запуска фонограмм 01–40;
- нижняя панель воспроизведения и таймлайн.

Для сборки требуется Windows и .NET SDK 8 или новее. Проект нацелен на .NET 8 и публикуется автономно для win-x64.


## Автопереход

Кнопка `AUTO NEXT` в верхней панели включает или выключает автоматический запуск следующей фонограммы после окончания текущей. При выключенном режиме воспроизведение останавливается в конце трека. Повтор текущего трека имеет приоритет над автопереходом.
